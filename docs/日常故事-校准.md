## 2. 校准工作流（换机器继续时照做）

1. **跑样**：

   ```bash
   cd backend
   conda run -n flask_env python \
     backend/scripts/preview_daily_story_batch.py \
     --story-type X --themes "主题1" "主题2" \
     --parallel 2 --out tmp/daily_x_baseline.json
   ```

   输出会打印：字符数 / 句数 / speaker 分布 / 开场 / 头尾句 / 妈妈句 /
   `quality`（grade + score + summary）与 punchline。结果 JSON 存 `tmp/`
   （已 gitignore），不提交。
2. **判定缺口**：对照各类型叙事契约（`docs/日常故事-类型.md` §3）
   与硬卡 / 观感输出，区分三类问题：
   - 生成总不达标 → 改 `line.py` 提示词或重试 hint；
   - 机读不变量漏判 → 改 `validate.py`（结构槽位，勿按主题词穷举）；
   - 写得不好但不违规 → 观感降分或改 `line.py`，不做生成硬拦。
3. **防回归**：每次改动给 `backend/tests/` 加单测（纯函数可测的部分），
   参考 `test_llm_script_title.py` 对 A 类角色自称的测试写法。
4. **收尾**：某类达标后置 `quality_ready=True`（如已开则确认）、
   有 D1.5 需要时再开 `story_plan.ENABLED`，并更新 §1 表与本节。

## 4. 红线与分工

- **三层分工**（`.cursor/rules/daily-story-validate.mdc`）：
  - 叙事与措辞 → `line.py` / `prompts.py` / 重试 hint；
  - 机读不变量 → `validate.py`（字数、speaker、末段结构槽位）；
  - 观感 → `quality.py`（类型 pattern，不按单篇主题加 regex）。
- **validate / patch 允许**：与类型契约对齐的抽象不变量、可程序判定且
  全类型通用的规则；**禁止**：单篇 / 单主题台词词表、regex 穷举
  「好/坏措辞」、把观感扣分问题做成生成硬拦。
- **本地修稿边界**：patch 只做类型级结构修补，禁按主题关键词分支改写
  台词；内容类硬卡不过一律交 LLM 重试。

### 2026-08-07 C/B 提示词修复（架构改造后首轮人读审稿，经专家评审达成一致）

### 2026-08-07 C 类用词铁律——占有系 vs 接触系动词（专家四轮评审）

用户再点稿1开场「茶几上遥控器怎么你也按着」：「完全不对，『按着』不对，好好研究下用词」。
先做 C 类遥控器全稿动词分布盘点：占有系（拿 32/抢 13）vs 接触系（碰 31/按 22/搭 9/摸 8）
vs 状态系（松 9/放 12/掉 7/捡 1）——接触系总量惊人，提示词没教模型「用词分家」。与专家
讨论达成：

1. **占有系动词**（拿到/抢到/抓到手/攥着/抱着/端着/占着/坐上去/夹起来/切下去）：动作对象
   是争点物本身、取得控制权，可当占有主张、可当赛规判据。
2. **接触系动词**（碰/摸/搭/挨/蹭/按/压/点）：只描述局部接触、不构成占有，**严禁当占有
   主张、严禁当赛规判据**，只能作为被当场击穿的临时理由（「碰到不算，拿起来才算」「你
   只是按着，又没拿起来」）。**「按」的宾语只能是按钮（按电视/按键）**——「按着遥控器」
   用词错，孩子占有一定说「我先拿到的」「我抢到手里了」「遥控器在我手里」。
3. **状态系动词**（松手/放手/掉/捡）：只描述物态变化，不作初始主张。
4. **遥控器主题特殊规则**：第一层冲突是「谁占有遥控器」（只能拿/抢/抓），「按电视」是
   占有后的第二层结果，**全场禁止用「按/按键/按电视」主张占有权**；「按」只能出现在冲突
   解决之后（一方拿到遥控器走向电视按按钮）。专家重排示范开场：昭昭「我先拿到的！遥控器
   归我！」灿灿「你抢那么快干嘛！是我先看见的！」昭昭「看见有什么用，我拿到的！谁拿到

1. **判据动词白名单**：全文胜出/归属主张句中，判据动词必须全部属占有系（拿到/抢到/抓到/

   - **结果系**（画面出来/出画面/灯亮/有声音）：出现即漂移，无一豁免——结果系是次级目标侵
     入，画面是否出来不构成占有判据。
2. **击穿豁免**：接触系 +「X到不算」当场击穿（碰到不算，拿到才算）不拦；但同一句若再出现

不同角色，没有「两人抢做同一件事争完成度」的竞争；而座位/撕/削/倒都是两人抢做同一动作。

**根因修正（专家确认成立）**：C 类核心矛盾 = 「双方抢做同一动作争完成度」→ 必然分级杠精；
不是判据类型（先后 vs 仪式）问题，是**是否让双方争夺同一动作的执行权**问题。

**治本方向 = 动作分派型赛规**（专家强烈推荐）：规则把不同动作/角色分派给不同的人——
我切你选/我分你先挑/我搬你摆/我拆箱你清点/谁洗谁晾（切分搬拆是执行权、选挑摆清点是优先
选择权），两人没有「抢做同一件事」可争；冲突点 = 提出分派的人利用执行权作弊（切一大一小/
分得不均/搬一大摞/暴力拆箱），被对方按字面行使优先权反噬（选走大块/挑走多的），回旋镖落
在「你刚说我切你选/我先挑」。外部裁判/随机仪式（猜拳/数三下/妈妈裁定）不推荐作 C 类主干
（回旋镖无生根处），仅可作背景或收束推进。

**落地**：

- `c/line.py`：判据铁律区加「动作分派型铁律」（✅分派型主题 / ❌双方抢做同一动作高危险）+
  「禁分级句式」（X不算Y才算 只许 1 次击穿）；theme_user_append 赛规优先动作分派型，
  高风险主题禁用清单 = 谁先拿到/坐上/撕开/削出/倒满（双方同时执行同一动作），分派型内
  禁滑回猜拳/数三下/谁先拿到 等第三方判据（糖果 88/拆箱 85 稿中段曾因此乱）。
- `c/validate.py`：新增 `_RE_GRADING_BICKER` 分级句式硬卡——「X不算，Y才算」/「Y才算，
  X不算」比较型杠精句 ≥2 次即判据漂移整稿重抽；合法击穿句（碰到不算，拿到才算）1 次豁免；
  词表覆盖手部接触（碰/摸/搭/勾/抓/攥/握/拿稳）与动作仪式（坐/撕/削/倒/举/戳/坐稳/坐实/
  撕开/削出/倒满），**不含切/分/挑/搬/摆/拆**（动作分派型合法对白不得误伤）。
- 防回归：`tests/test_llm_script_title.py` +4（分级杠精拒/仪式型分级拒/单次击穿放行/动作
  分派型对白放行）。全量 674 过（visual_brief 2 个过期断言已随「规则改正向表述」重构更新）。

**验证（两轮批量，动作分派型 5 主题）**：

- 一轮（无猜拳禁令）：5/5 ok 0 FAIL——糖果 88/拆箱 85/新书 83/碗碟 78/蛋糕 76。糖果 88 稿
  中段滑入猜拳/谁先拿到，靠回旋镖收住；拆箱 85 稿中段「攥着不算举起来才算」击穿后接猜拳。
- 二轮（加猜拳禁令）：5/5 ok 0 FAIL——糖果 89/蛋糕 85/新书 85/拆箱 81/碗碟 80。糖果 89 稿
  是理想形态：「分的人后挑」→ 姐姐自己分完 → 弟弟按字面先挑多的 → 回旋镖「你说的分的人
  后挑，我分完你挑」→ 姐姐嘴硬。剩余 80-85 是观感略乱（开场锚点/中段话痨），非结构漂移。
- **结论：动作分派型治本方向成立**（两轮 10 稿 0 FAIL，对比纯先后/仪式型批次 FAIL 崩盘）；
  达标率从 0/8 提到 1/10（89）+9/10 无 FAIL。猜拳禁令后糖果 89 稳定，但 80-85 档仍低于 88
  目标，属观感打磨空间（开场锚点、中段收敛），非硬卡缺口。
