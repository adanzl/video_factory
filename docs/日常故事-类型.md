## 3. 叙事契约（抽象）

### 3.0 A–E（日常故事已落地）

| 代码 | 名称 | 公式 | 收束 | 边界 |
| --- | --- | --- | --- | --- |
| A | 权威翻车 | 立规→一锤可拍→埋句→反噬 | 末四拍（引话/那不一样/哪里不一样/破功） | 非 C/D 主线 |
| B | 结盟翻车 | 结盟→走样→甩锅→露馅 | 露馅后仍嘴硬甩锅 | 主戏姐弟 |
| C | 公平执念 | 争同一资源→双规则→回旋镖 | 被戳穿方末句嘴硬 | 非管教权威主线 |
| D | 字面执行 | 合理规矩→歪读执行→跑偏→叮嘱方破规 | 执行方用原话回旋镖 | — |
| E | 妈妈破功 | 妈妈立论→追问→改口→闭环 | 妈妈破功 | 妈妈可略多台词 |

### 3.2 F/G/H/I（金故事扩展，待或部分落地）

| 代码 | 名称 | 公式 | 收束 | 边界 |
| --- | --- | --- | --- | --- |
| F | Threat 互升级 | 互相威胁→加码→僵持/露怯 | 无 A–E 标准收束 | 暂不入 A–E 任务注入 |
| G | 嘴硬心软 | 互怼/数落→真情 pivot→愣住→暖收 | 暖收或嘴硬里带软（多样） | 非 C/F/A 主线 |
| H | 第三方化解 | 升级/僵持→第三方定责劝和→仪式性和好 | 表演性道歉/拉手/齐声承诺 | 非 G 内部 pivot |
| I | 问倒收束 | 争锋→价值高地→灵魂拷问→语塞 | 赢家嘴硬一招制敌 | 无 A 式反噬/破功 |

#### I 类不变量（2026-08 立项）

##### I：不是什么

- 不是 **A 权威翻车**——立规者全程占上风，**无反噬/破功**。
- 不是 **C 公平执念**——赢点不是回旋镖互戳，是**不可答问题**问倒。
- 不是 **G 嘴硬心软**——无真情 pivot，收束是赢家嘴硬总结。

##### I：公式

```text
争锋 / 互怼（可含双规则拉扯）
  → 立价值标准 / 道德高地（须可拍一句）
  → 灵魂拷问：抛出不可答 / 不可接问题
  → 对方语塞 / 败北
  → 赢家嘴硬总结（一招制敌）
```

##### 与 A / C / M8 边界

| | A 权威翻车 | C 公平执念 | M8 一锤可拍 | I 问倒收束 |
| --- | --- | --- | --- | --- |
| 赢法 | 一锤后反噬 | 双规则回旋镖 | 泛一锤（常标 A） | 灵魂拷问问倒 |
| 收束 | 末四拍破功 | 被戳穿方嘴硬 | 可反噬可不问倒 | 赢家嘴硬，无反噬 |

##### I：金故事映射

- 机制 **M11 灵魂拷问** → **structure_type=I**。
- 若 beat 仅为泛一锤且后续有反噬 → 仍标 **M8+A**；勿与 M11+I 混标。

##### I：落地节奏

1. 现仅 gold_story / gold_chat 侧标 I；`punchline_explain` 写 `I类问倒收束…`。
2. 同类金稿 **≥3 篇** 再实装 `story_types/i/` + validate + H5 注入。
3. 正例：`BV1Ci4y1L7jg`（我爱学习你爱吗）。

#### G 类不变量（2026-08 立项）

##### G：不是什么

- 不是「普通日常」——场景日常，类型看**矛盾怎么转**。
- 不是泛「互怼」——F/C/A 表面也可互怼，G 卡的是**情感拐点**。

##### G：公式

```text
互怼 / 数落 / 互损（escalation，可借 M4 递台词）
  → pivot：意外真情或护短一句
  → beat：对方愣住 / 接不住
  → 收束：暖收或嘴硬里带软（保持多样，不锁单一模板）
```

##### pivot 句（谁说不限定）

- **谁身份合适谁来说**：可从年纪（姐大弟小）、性别、当场强弱切入。
- 常见方向（非穷举）：弟护姐 / 姐骂完自己先软 / 被数落方突然认怂护对方。
- pivot 须**可画、可拍**，不能只是继续对骂或抛 Threat。

##### 收束多样性（刻意不锁死）

- **纯暖**：擦药、约定、「那说好了」、相视而笑。
- **半嘴硬**：「撑腰呢！」「哼，小屁孩还管我」——嘴硬壳里已软。
- **禁止**作主线的：C 式回旋镖戳穿、F 式威胁僵持不收、A 末四拍、E 妈妈立论链。

##### 与 C / F 边界

| | C 公平执念 | F Threat | G 嘴硬心软 |
| --- | --- | --- | --- |
| 吵什么 | 谁对谁错 / 谁拿 | 谁怕谁 / 谁退 | 态度 + 感情 |
| 赢点 | 规则回旋镖 | 威胁压过对方 | 一句真心破防 |
| 收束 | 被戳穿方嘴硬 | 僵持 / 露怯 | 暖或半暖 |

##### G：金故事映射

- 机制 **M4 递台词** 且 beat 为「骂完→护短/真心→软化」→ **structure_type=G**。
- 若 beat 是争物、双规则、公平回旋镖 → 标 **M1/M2 + C**，不要并进 G。

##### G：落地节奏

1. 现仅 gold_story / gold_chat 侧标 G/H；`punchline_explain` 写 `G类嘴硬心软…` / `H类第三方化解…`。
2. 同类金稿 **≥3 篇** 再实装 `story_types/g/` + validate + H5 注入。
3. 文档**不贴长对白正例**；回归见金稿 `BV1ms411a7im` 或 `gold_chat_batch`。

### A 类不变量（程序与观感对齐）

1. **一锤**：中段有可画场面，事实/动作全文自洽。
2. **埋句**：灿灿前文有一句可被末段引用的原话。
3. **末四拍**：说话人顺序与功能固定（见上表）。

文档**不贴长对白正例**；回归用 `preview_daily_story_batch.py` 或线上稿。

### E 类补充不变量

1. **挑食顺序固定**：若题面是
   `不许挑食 + 青菜拨到碗边`，必须是
   `妈妈先训孩子不能挑食 → 孩子再抓妈妈拨开青菜`。
   禁止写成
   `孩子先问你怎么拨开了 → 妈妈再说不许挑食`，
   这会把同一条规矩写成倒因果。
2. **抓现行后先开脱，不回训**：孩子点出
   `拨到碗边 / 拨开青菜` 后，下一拍须进入开脱
   （`晾着 / 配饭 / 等会儿` 等）。
   **开脱优先由另一孩子假替妈说**（口吻像帮腔，实则讽刺）；
   也可妈妈自己开脱。禁止妈妈立刻回训
   `你自己也一口不动`，否则主冲突会从
   `妈妈破功` 漂回 `孩子不吃菜`。
   **妈妈「不许挑食」只立一次**，开场后再训同一句即违规。
3. **闭环抄开场原词**：开场若说的是
   `不能挑食`，收束就优先扣 `不能挑食`；
   开场若说 `不许挑食`，收束就优先扣 `不许挑食`。
   不要在闭环时随手换词。
4. **挑食篇幅宜短**：优先做成
   `8–14 句、约 200–280 字` 的紧凑稿。
   缺字时宁可补可拍追问，也不要靠
   `打自己脸 / 数叶子 / 证明夹菜`
   这类注水撑长。
5. **优先好笑模板（假开脱）**：
   `妈妈立规 → 孩子1戳穿 → 孩子2假替妈解释（讽刺）→`
   `孩子1再追 → 孩子2继续越帮越黑 → 闭环 → 妈妈破功`。
   中段妈妈宜少说话；`不一样 / 大人`
   只许出现在孩子2的讽刺帮腔里，禁妈妈当真开脱。
   孩子2主语须是妈妈（如「妈妈会吃的，上次是意外」），
   禁对孩子1甩「你别翻旧账」。
   孩子对妈妈少用当面「你」硬质问（粗鲁）；宜侧写大人/自己说…。
   观感好笑维对「假开脱帮腔」加分（孩子讽刺护妈、越帮越黑）。
6. **钓鱼开场（首选）**：孩子装不懂问规矩 → 妈妈顺口立规作答 →
   正文首句孩子亮底牌抓现行。钓鱼句须直问核心规矩本身
   （换拖鞋题问「不穿鞋可以进屋么」，勿问「鞋放哪」这类边角）；
   开场句勿点破妈妈现行；孩子已点破时，
   禁妈妈回头命令孩子去做孩子已做到的事（训错对象）。
7. **追问链逻辑一口径**（2026-07 换拖鞋案例沉淀）：
   先认准 theme 里妈妈破的哪条、现行是什么，全文不变形
   （「穿着鞋进客厅」指出门的鞋，写成拖鞋就不违规了）；
   每条证据须指向违规，禁反向（球鞋刚脱下还热乎=她换过鞋了）；
   每拍须反驳对方刚说的开脱，禁证明没人否认的事、禁跑去吵
   别的双标旧账；孩子2帮腔理由禁重复；推理链关键一环须在
   台词里说出口，指代（那/那块）须能唯一对上前一句。

### D2 / 修订策略

1. **首稿**：高温、关 `thinking`。先钉「规矩词 + 歪读点 +
   必然后果」，写出不知变通骨架。
   **接受偏短**（不因字数不够打回重开）；不是故意写短。
2. **第一次重试**：开 `thinking`，在上一稿上定向修订；
   **字数一次补到 ≥280**（句数 13–14），不要推翻重写。
3. **期望轮次**：正常 `首稿 + 1 次重试` 成稿；再留 1 次兜底。
   勿把同一硬伤过早截停，也勿指望第三、四轮慢慢凑字。

### D 好笑核（字面规矩执行歪）

先想清三件事再写对白，缺一则难笑：

1. **合理规矩词**：听着没错（系紧 / 轻轻 / 别浇多）。
2. **歪读点**：同一个词的第二种读法
   （系紧→死结焊脚；轻轻放进箱→先轻轻码成塔）。
3. **必然后果**：由歪读推出来，可拍
   （解不开 / 塔倒 / 水溢）。

笑点在「规矩没错，认真执行却帮倒忙」；
不在倒了本身，不在轻轻放×N 流程复读。

任务 55 说明 D 类要真好笑，还得多一条：

1. **叮嘱方中段要连续报新惨状，不要重复催**：
   不是“别动 / 快点 / 别拉”换词复读，
   而是像 `白印 → 勒红 → 鼓起 → 脚麻/焊死` 这样一层层升级。
2. **执行方每次都把同一歪读再推进半步**：
   不是反复说“按你说的做”，而是
   `拉到底 → 再绕一圈 → 打成花生米结 → 焊死`。
3. **收尾三拍要对齐**：
   破规须具体（指甲抠/赶紧解开），
   回旋镖须点破「怎么现在又上手来解了」，
   末句只哼/算了，禁止哼完又拿剪刀。

这些内容在 D 类（`ENABLED=True`）时应先落在
`punchline_blueprint`（`beats` / `persona` / `fix` / `boom`），
再由 Flash 展开，而不是指望与对白同跳「写完再解释」。

## 5. 校验与修稿路由

- 通用：`prompts.validate_daily_story_json`（字数、连说、单冲突、贴题等）。
  贴题硬卡只判「主题实词一个都没落到正文」的硬跑题
  （2026-07 案例：E 题面看电视、成稿整篇套挑食正例）；
  命中后重试丢弃上一稿、按主题原词重写，不在跑题稿上修补。
  类型示例正文（如 E 挑食正例）须标注适用题面，防整段盖题。
- 类型扩展：`story_types.append_type_body_validation_errors`。
- 开场类型：`story_types.validate_type_opening`（传入 `type_code`）。
- 本地修稿：`prompts.try_local_patch_daily_story_body` 内调用
  `story_types.patch_type_body`。**patch 只做类型级结构修补**：
  允许删句/去重/改 speaker/引话接地及不含主题词的通用短句；
  **禁止按主题关键词分支改写台词**；D 另禁本地垫字
  （2026-07 浇花案例：兜底模板整段盖台词还刷高观感分）。
  内容类硬卡不过一律交 LLM 重试。新增规则前先读各
  `*/patch.py` 文件头红线。

解析类型：`parse_story_type_code`（`story_type` 或 `punchline_explain`）；
与选题不一致时以 punchline 为准。

### 5.1 硬卡边界（勿剧情穷举）

- **validate / patch**：只卡机读**不变量**（结构槽位、speaker、与类型契约一致的
  末段形态）；与 `*/quality.py` 共用抽象 pattern 时避免两套真理。
- **line / prompts / 重试 hint**：赛规措辞、反例、单主题创作约束（如更急赛规怎么写）。
- **禁止**：在 `validate.py` 为单篇剧情或词表写 regex（如某句禁用词）；
  「写得不好」走观感降分或改提示词，除非明确要求生成硬拦。
- Agent 细则：`.cursor/rules/daily-story-validate.mdc`。
