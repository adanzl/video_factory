# 文生图提示词槽位化方案

> 2026-08-20。范围：daily_story / chat 流水线的文生图（T2I）提示词生成。
> 背景：`docs/提示词构建.md` 的 A3 链路。本方案替换原「多来源文本拼接 + regex
> 清洗」的实现，解决提示词自相矛盾问题（详见后文）。
> 相关：`docs/日常故事.md`、`docs/日常故事-校准.md`。

---

## 0. 问题与目标

旧实现把 LLM 的 `visual_brief`、分镜1场景锚点、家具补回、各类硬锁按顺序拼接，
冲突清洗只作用于拼接前的 `visual_brief`，后注入的内容（场景锚点、家具、硬锁）
从不做冲突仲裁，regex 补丁打地鼠，产出频繁自相矛盾。实测（job 80）：

- 「沙发和茶几上没有任何物品」与「茶几上放着遥控器和空水杯」并存
- 「茶几上放着遥控器和空水杯画面中有茶几」重复且粘连（句号被 strip）
- 「昭昭龇牙咧嘴使劲」与口型锁「昭昭嘴巴自然闭合」矛盾
- LLM 动作描写与硬锁动作描写双重存在且不一致
- 清洗残留无主语断句（「眼睛眯成缝。」）

目标：矛盾在**结构层**就不该产生，而非事后抓。

---

## 1. 核心原则

1. **单一负责人**：每类信息只有一个槽位产出，其它环节禁写
2. **清洗内聚**：scrub 只在槽位内部（产出方保证自己干净），禁止跨槽位 regex 互改
3. **拼装零智能**：拼装器只 join，不做任何判断
4. **审核独立于生成**：L1 结构审核（代码）+ L2 语义审核（LLM reviewer）

---

## 2. 架构总览

```text
分镜脚本（dialogue + visual_brief + object_states 结构化字段）
  → 状态机层（道具状态快照：跨镜继承 + 变更事件校验）
  → 槽位渲染层（代码，零判断只 join）
  → 审核层（L1 代码全量 + L2 LLM 可选档位）
  → 出图 → 出图质检（现有）
```

## 3. 槽位定义总表

| # | 槽位 | 负责环节 | 字数 | 内容 | 禁写 |
| --- | --- | --- | --- | --- | --- |
| S1 | 风格 | 常量 | ~30 | 涂鸦画风定调，全片唯一 | 光照、具体场景 |
| S2 | 场景锚点 | code（模板，按 setting） | 10-20 | 地点 + 硬锚点名词 | 小物件、材质 |
| S3 | 角色外貌 | 常量（子块拼装） | ~86（2 人）/ ~130（3 人） | 外貌基块 + 身高锁 + 发色锁 | 道具状态 |
| S4 | 本镜画面 | **LLM → JSON + 代码加厚** | ~80–130 | 场景开场、动作、**叙事站位** | 外貌、口型、道具数量 |
| S5 | 道具状态 | **code 状态机** | ~60 | 物品数量/位置/持有人/形态 | 人物动作 |
| S6 | 口型锁 | code（dialogue 推导） | ~30 | 谁说话谁闭嘴 | — |
| S7+8 | 镜头参数 | code（shot_type+cast） | ~40 | 景别、光照 | 叙事站位、服装标签构图锁 |

删除：句首锚点、句末重申、人数锁重复段、fixed_furniture 补回（并入 S2/S5）。

**总预算**：二人镜约 350 字，三人镜约 380 字（粗略，随 cast 略浮）。

## 4. 常量压缩（S1/S2/S3，已过 Agnes 评审）

### S1 风格（45→30字）

```text
儿童情绪涂鸦风，彩铅蜡笔混合笔触，高饱和色彩，涂色出界，手工感。
```

删「线条用力不均」「橡皮擦拭痕迹」（后者降级为可选，画风过干净时加回）。

### S2 场景锚点（通用模板，按 setting 生成）

```text
格式：地点，硬锚点A，硬锚点B，硬锚点C（，硬锚点D）
```

- 硬锚点按**面积从大到小**排序，室内≤3、户外≤5
- 只保留**一个**辨识度形容词（"圆形""红色"）
- 小物件归 S5；**地垫/地毯例外**（地面锚点，写 S2）
- 10-20 字

| 场景 | 成品 |
| --- | --- |
| 客厅 | `客厅，圆形地垫，沙发，茶几。` |
| 厨房 | `厨房，水槽，餐桌，窗户。` |
| 户外 | `小区公园，滑梯，沙坑，长椅。` |

### S3 角色外貌（子块拼装）

| 子块 | 成品 | 字数 |
| --- | --- | --- |
| 昭昭基块 | 昭昭：7岁男孩，黑色超短发露耳露后颈，圆脸，蓝色短袖T恤深蓝色短裤，蓝白运动鞋。 | 37 |
| 灿灿基块 | 灿灿：10岁女孩，黑色单侧高马尾，粉色卫衣蓝色长裤，粉红运动鞋。 | 30 |
| 身高锁 | 昭昭比灿灿矮约半个头。 | 11 |
| 发色锁 | 灿灿头发通体纯黑。 | 8 |
| 地垫变体 | 灿灿鞋→`赤脚仅穿白袜子`；昭昭→`双脚均已穿好一双蓝白运动鞋` | 按需替换 |

## 5. S4 本镜画面（LLM → JSON → 模板渲染）

LLM 输出 `visual_subjects`（每角色一条），字段字数在代码侧不硬截，生成规则约束：

| 字段 | 上限 | 示例 |
| --- | --- | --- |
| posture | ≤12 字 | `站在茶几前` |
| action | ≤15 字 | `双手背在身后` |
| expression | ≤10 字 | `皱眉瞪眼` |

`render_visual_subjects` 模板渲染为 brief 短句；若合成 brief **薄**
（无场景开场，且 < 130 字、缺沙发/茶几/地垫等锚点），
`enrich_thin_daily_visual_brief` 扩成 64/7 式长 prose（§11.2，约 90–130 字）。

legacy JSON 示例（标准流水线已改用 visual_subjects）：

```json
{
  "subjects": [
    {"id": "zhaozhao", "action": "双手拉紧鞋带", "expression": "皱眉抿嘴", "posture": "身体前倾"},
    {"id": "cancan", "action": "站在一旁看", "expression": "微笑", "posture": "双手背在身后"}
  ]
}
```

防越权：JSON schema + L1 字段级校验（S4 禁写外貌/口型/道具数量词）。

## 6. S5 道具状态（状态机）

状态来源上移到分镜脚本层：

```json
{
  "shot_id": 12,
  "object_states": [
    {"object": "粉鞋", "form": "loose_knot", "holder": "none", "position": "on_mat"}
  ]
}
```

- **跨镜传递**：每镜继承上一镜状态版本，只有显式"状态变更事件"才允许改
- **状态机校验**：转移合法性（散开→打结→被拎起 ✓；打结→散开 未声明 ✗）
- **后置确认**：S5 在 S4 之后，按 S4 的物体交互确认/修正状态，不是"预言"
- 状态缺失 → 报错升级 QualityReport，不猜

## 7. S7+8 镜头参数槽

S7 光照 + S8 景别，由 `_daily_lighting` + `_daily_composition` 产出。

**分工**：

| 槽 | 写什么 | 不写什么 |
| --- | --- | --- |
| S4 | 叙事站位、动作、场景开场 | 景别 |
| S7+8 | 景别（中景/特写）、窗光 | 站位、服装标签、严格左/中/右 |

三人镜 S7+8 仅补 `中景三人同框，全身可见`。
若 S4 无左右序，才补 `画面从左到右是…`；S4 已有 `画面左边` 则跳过。

**已移除**（2026-08-20 实测）：`严格左蓝T恤…昭昭、中…妈妈、右…灿灿`
服装构图锁——job 81/12 无锁版（321 字）出图正常，与有锁版（382 字）等价。

## 8. 审核流程

### L1 结构审核（code，每段同步，全量）

| 检查项 | 级别 |
| --- | --- |
| 槽位字数超限 | minor |
| 冗余检测（同一实体被两次描述） | minor 自动修剪 |
| 矛盾检测（对立谓语共现：有/无、散开/打结、在手中/在垫上） | major |
| 否定词检测（不/无/没有/禁止+名词；**S1/S3 豁免**，只查 S4/S5） | major |
| 角色集合一致（S3 cast ↔ S4 subjects） | major |
| 口型唯一性（S4 禁写嘴部/牙齿/笑容） | major |
| 数量一致（S4/S5 数量词 vs 状态机） | major |
| 主语完整性（禁无主语断句） | minor |
| S4 越权（出现场景/外貌/风格词） | major |
| 儿童安全规则 | major |

冲突对表**自动沉淀**：L2 每审出一个矛盾，把 (名词, 谓词对) 写回表。

### L2 语义审核（LLM reviewer，异步）

- 输入：带槽位标记的拼装结果 + 本段 dialogue + 结构化状态快照
- 不同模型/低温度 + few-shot，**只报确定矛盾**（宁少勿乱）
- 输出 JSON：`{contradictions, redundancies, unpaintable}` 注明槽位号
- 槽位级重生：S4 用其他槽位摘要+矛盾描述重写；S5/S6 先修状态机再重渲染
- 重试上限 2 次，仍失败 → `QualityReport(major, fail_stage="script")`
- 档位：仅 L1 命中 / 抽样 / 全量（控制成本）

## 11. 拼装运行时规则（2026-08-20，job 81 校准）

本节记录 `assemble_daily_t2i_prompt` 在槽位表之外的**代码侧规则**。
实现：`image_prompt.py`、`visual_brief.py`。

### 11.1 槽位拼装顺序

最终 join 顺序（非文档初稿的 S1→S3→S2→S4…）：

```text
S1 风格 → S2 场景锚点 → S4 本镜画面 → S5 道具状态 → S3 角色外貌
→ S6 口型锁 → S7+8 镜头参数
```

理由：场景与动作前置，外貌/构图后置，贴近 64/7 等成功样本的 prose 节奏，
三人镜模型不易因先读外貌块而克隆角色。

### 11.2 S4 薄稿加厚（`enrich_thin_daily_visual_brief`）

**触发**：分镜含 `visual_subjects` 且 `visual_brief` 不够「场景开场」
（无地点+陈设铺陈，或字数 < 130 且缺沙发/茶几/地垫等锚点）。

**不触发**：无 `visual_subjects` 的老数据（地垫鞋专项等），走原自由文本链。

加厚模板（对齐 job 64/7）：

1. **场景 + 妈妈合句**（须含角色名，避免 `_strip_vb_scene_anchor_sentences`
   误删纯场景句）：
   `客厅，沙发、茶几清晰可见，妈妈站在茶几前，单手叉腰，皱眉瞪眼。`
2. **孩子左右锚点**（正面写，不用相对虚词）：
   `画面左边是昭昭，双手背在身后，瞪大眼睛。`
   `画面右边是灿灿，双手下垂，撇嘴。`

数据来源：`setting` 地点、`scene_anchors`、`visual_subjects` 各字段；
经 `_sanitize_subject_action` / `_sanitize_subject_expression` 消毒后渲染。

**禁止**在 S4 末尾补 `画面中有薯片` 类泛化尾巴；道具只由 S5 负责。

### 11.3 站位虚词：正面改写（非禁止）

`scrub_daily_visual_brief` / `render_visual_subjects` 内
`_resolve_vague_spatial_terms`：

| 原文 | 改写 |
| --- | --- |
| `{角色}站在{物件}对面` | `{角色}站在{物件}前` |
| `{角色}站在对面` | `{角色}站在{anchor}前`（anchor 按茶几/沙发/…优先级） |
| `{角色}蹲在{另一角色}对面` | `{角色}蹲在画面{左/右边}` |
| `{角色}站在{角色}旁边` | `{角色}站在画面{左/右边}` |

LLM 生成规则同步：写「茶几前 / 画面左边」，不写「禁止相对站位」。
门口场景写「单开门半开，门外柔和白光」，不写「空无无人」。

地垫鞋专项 `_daily_zhao_floor_shoe_watch_action` 等硬编码句亦遵守：
`昭昭蹲在画面左边`（禁止硬写「蹲在灿灿对面」）。

### 11.4 三人镜 S7+8

- 三人：固定 `中景三人同框，全身可见`（不因特写走单人分支）
- 站位全在 S4（加厚 + 画面左/右边）；S7+8 不再出服装构图锁
- 地垫鞋 compact 专项仍保留自有左右句（独立 prompt 路径）

### 11.5 S5 道具别名去重（`_collapse_object_aliases`）

`normalize_object_states` 与 `_render_object_states` 共用：

- 短名是长名子串时保留长名（例：`薯片` 并入 `薯片袋`）
- 同一镜 S5 只输出一条，避免「薯片袋 + 薯片」双描述诱发多袋/多物

### 11.6 其它正面表述

| 场景 | 规则 |
| --- | --- |
| 门 | 写「一扇单开门，一块完整门板」；半开写「门板边缘与门框之间露出一道空隙」 |
| 口型 | 仍仅 S6；S4 经 `_scrub_vb_mouth_words` 剥嘴部动作词 |
| 质检 L1 | 否定词白名单已去掉 cast_lock 相关条目 |
